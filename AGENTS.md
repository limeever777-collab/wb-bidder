# Биддер WB и Telegram-боты

Пиши пользователю по-русски, коротко и по делу.

## Состав проекта

- `bidder.py` — биддер рекламы WB, управление ставками и минус-фразами.
- `tg.py` — общий модуль Telegram: сообщения, кнопки и ответы на нажатия.
- `blocks_watch.py` — проверка блокировок и скрытий WB/Ozon и уведомления в Telegram.
- `config.json` — актуальные лимиты, целевой ДРР и разрешения на запись.
- `автозапуск_com.wb.bidder.plist` и `автозапуск_com.wb.blocks.plist` — задания macOS.

Рабочая версия на исходном Mac: `/Users/d/wb-bidder`. Этот каталог — чистая копия для Codex без секретов и рабочих данных. Подробное описание — в `README.md`.

## Обязательные правила безопасности

- Не выводи ключи и токены в чат, не вставляй их в код и не загружай в репозиторий. Они хранятся только в локальных `tokens.json`, `ozon_keys.json` и `telegram.json`.
- Перед `--apply`, `--rollback`, изменением ставок или минус-фраз, правкой `config.json` и изменением автозапуска покажи предполагаемые действия и дождись явного «да».
- Не запускай биддер с записью одновременно на двух компьютерах.
- Обычный запуск `python3 -I bidder.py` без `--apply` только строит план, но обращается к API и требует локальные ключи.
- Не придумывай содержимое отсутствующих секретов и не проси прислать его в чат. Пользователь добавляет файлы локально.

## Работа с кодом

- Python 3, сторонние зависимости не требуются.
- После изменения Python проверяй файлы через `python3 -m py_compile`.
- Не меняй алгоритм ДРР и правила ставок без отдельного запроса пользователя.
- Не включай автоматический режим минус-фраз: сейчас в `config.json` установлен `auto_minus.mode = confirm`.
- Состояние, кэш, отчёты и бэкапы не входят в проект и перечислены в `.gitignore`.

## Текущий рабочий режим

- В `apply.cabinets` разрешены Swiss Health и BioNature.
- На исходном Mac `com.wb.bidder` запускает `bidder.py --apply` каждые 30 минут.
- `com.wb.blocks` запускает `blocks_watch.py` каждые 3 часа.
- При переносе автозапуска на другой Mac нужно исправить абсолютные пути `/Users/d` в plist, если там другой пользователь.
